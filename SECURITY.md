# Security policy

Activra [`1.0.0-rc.4`](https://github.com/Mem0ryPool/activra-desktop/releases/tag/v1.0.0-rc.4) is a Windows pre-release. No public release is currently declared as supported.

## Reporting a vulnerability

Do not disclose a suspected vulnerability, exploit, credential, or user data in a public issue. After the repository is published, use GitHub's **Security → Report a vulnerability** flow. The owner must enable private vulnerability reporting before publication.

Include the affected version or commit, operating system, reproduction steps, impact, and any suggested mitigation. Use synthetic data and remove personal information from logs or screenshots.

The project does not request production credentials or access to real user data for verification.
